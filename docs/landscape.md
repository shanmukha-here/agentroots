# Landscape and positioning

The August 2026 landscape audit found several close systems. AgentRoots is not the first durable
cross-agent memory or the first project-state graph.

- [ProjectMem](https://github.com/riponcm/projectmem) combines typed development events, stale
  decisions, failed-attempt warnings, compact briefings, code structure, and editable future intent.
  Its [paper](https://arxiv.org/abs/2606.12329) describes an append-only event model and pre-action
  warning gate.
- [CodeMem](https://github.com/kunickiaj/codemem) combines automatic cross-harness capture, local
  SQLite hybrid retrieval, hooks, compact expansion, a viewer, synchronization, and distillation.
- [Knomit](https://knomit.io/docs/overview/) provides reviewed, typed, provenanced facts with
  confidence, hypotheses, agent branches, consensus, update, and retraction.
- [Agent Memory System](https://github.com/rrrrrredy/agent-memory-system) is close on append-only
  evidence, candidate validation and promotion, bounded retrieval, and harness adapters.
- [Remnic](https://github.com/joshuaswarren/remnic) covers cross-harness governed memory,
  provenance, temporal supersession, and review queues.
- [10x](https://github.com/z3z1ma/10x) defines a Markdown discipline for decisions, research,
  tickets, evidence, review, and unresolved follow-up work.
- [Atomic](https://github.com/atomicdotdev/atomic) combines goals, intents, memory, source changes,
  agent attribution, review, and code intelligence inside an alternative version-control system.
- [Hindsight](https://github.com/vectorize-io/hindsight) provides a mature general memory system
  with structured recall, but does not target AgentRoots' reviewable research frontier.
- [RKA](https://github.com/rka-project/rka-core) covers typed research knowledge, evidence, claims,
  decisions, missions, literature, and visualization.
- [OpenArx](https://openarx.ai/) provides a scientific claims graph, provenance, support/dispute
  relations, and forward-looking research cycles over a shared corpus.
- Flowcept and AiiDA capture execution and scientific provenance. MLflow and Trackio track runs,
  metrics, and artifacts.

AgentRoots targets the intersection as a small, repository-clean, cross-harness protocol. Its
specific combination is an active Goal, Question, Hypothesis, Experiment, Finding, Decision, and
Evidence graph; an isolated untrusted episode archive; independent review; evidence-reference
requirements; typed core and adapter verification; contradictions and staleness; goal resolution and
reopening; compact frontier packets; proactive prompt and tool-boundary retrieval; and external run
references without owning orchestration, source control, execution, or artifact storage.

Position as **shared, evidence-backed project knowledge across agents and sessions**, not as an
agent orchestration platform. Memory, planning, and provenance systems overlap. AgentRoots connects
past attempts, current understanding, and future intent in one governed project graph. Its frontier
is the graph's unresolved work, not the entire product.

Search is evidence, not proof of uniqueness. Repeat the audit before public launch, measure the
claimed reduction in repeated inspection, and pursue interoperability instead of claiming adjacent
concepts as inventions.
